CU-O01 — REGISTRARSE, INICIAR Y CERRAR SESIÓN
----------------------------------------------
Actor      : Usuario B2C / Cliente B2B
Pantalla   : /autenticacion/register.html  y  /autenticacion/login.html

Pasos para demostrar:
  1. Ir a /autenticacion/register.html
     → Crear una cuenta nueva con cualquier email y contraseña
     → El sistema registra al usuario y redirige a /catalogo/home.html

     → El sistema autentica y redirige a /catalogo/home.html

CU-O03 — CONSULTAR DETALLE DE TRACK / ARTISTA / ÁLBUM / GÉNERO
---------------------------------------------------------------
Actor      : Usuario B2C o Cliente B2B
Usuario    : usuario.b2c@tracklytics.dev / Tracklytics2026!
Pantallas  : /catalogo/track.html   /catalogo/artist.html
             /catalogo/album.html   /catalogo/genres.html (catálogo)

Pasos para demostrar:
  1. Desde /catalogo/search.html buscar "aguacero" y hacer clic en el track
     → Pantalla /catalogo/track.html muestra: nombre, artista, álbum,
       género(s) concatenados (ej. "reggaeton / latin"), 7 atributos de audio
       (popularidad, energía, danceability, etc.) y gráfico radar
  2. Hacer clic en el nombre del artista (enlace en el detalle)
     → Pantalla /catalogo/artist.html muestra discografía y top tracks
  3. Hacer clic en el nombre del álbum
     → Pantalla /catalogo/album.html muestra tracklist completo
  4. Verificar que un track con múltiples géneros los muestra concatenados
     (ej. "pop / dance pop") en todas las vistas, sin filas duplicadas

CU-O04 — GESTIONAR FAVORITOS Y PLAYLISTS
-----------------------------------------
Actor      : Usuario B2C (exclusivo)
Usuario    : usuario.b2c@tracklytics.dev / Tracklytics2026!
Pantallas  : /catalogo/track.html  →  /biblioteca/library.html

Pasos para demostrar — Favoritos:
  1. Iniciar sesión como Usuario B2C
  2. Navegar a cualquier track (ej. buscar "aguacero")
  3. En la barra del reproductor (parte inferior), hacer clic en ♥
     → El botón se pone rosa (activo) de forma inmediata (optimistic UI)
  4. Ir a /biblioteca/library.html → pestaña "Favoritos"
     → El track aparece en la lista con géneros concatenados

Pasos para demostrar — Playlists:
  1. En la barra del reproductor, hacer clic en ⋮
     → Aparece el modal "Agregar a playlist"
  2. Escribir un nombre en "Nueva playlist…" y hacer clic en "Crear"
     → La playlist se crea y el track se agrega automáticamente
  3. Ir a /biblioteca/library.html → pestaña "Playlists"
     → La playlist aparece con el track
  4. Verificar que un Cliente B2B NO puede acceder a esta sección
     (iniciar sesión como cliente.b2b@tracklytics.dev → la biblioteca
     personal muestra mensaje de acceso denegado)
